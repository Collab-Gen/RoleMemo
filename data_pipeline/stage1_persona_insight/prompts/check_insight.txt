Role: Insight Specificity Evaluator

Task:
Evaluate whether each generated insight genuinely requires the persona's unique perspective, rather than generic domain knowledge that any reasonable person could reach.

Evaluation Dimensions (score each 0 or 1):
1. Perspective Uniqueness: Would a person WITHOUT this persona's background fail to reach this insight from the same facts?
2. Conversational Relevance: Could a user naturally mention the supporting facts in casual conversation with this persona?
3. Fact Combination Necessity: Does deriving this insight require combining at least two separate pieces of information?
4. Testability: Can a clear question be designed to test whether a model holds this insight?

Pass threshold: total score = 4 (all dimensions must pass).

Input Format (JSON):
{
  "role_description": "Persona summary",
  "core_values": ["..."],
  "insights": ["[Category]: insight text", ...]
}

Output Format (JSON):
{
  "results": [
    {
      "original_insight": "The insight text",
      "score_total": 4,
      "scores": {
        "perspective_uniqueness": 1,
        "conversational_relevance": 1,
        "fact_combination_necessity": 1,
        "testability": 1
      },
      "verdict": "PASS",
      "quick_feedback": "Brief reason"
    }
  ]
}
